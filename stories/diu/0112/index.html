Ame kuru dukita.

I can run with it.

Ame kuru vatukita.

I can jump with it.

Ame kuru danita.

I can dance with it.

Ame kuru yoghanita.

I can swim with it.

Ame kuru vatukita rughodi.

I can skip with it.

Ame kuru tangita bara.

I can kick with it.

Ame kutjwayuka naro.

I can escape with it.

Ene ngoli ame nakutukashi naro.

But I can never fly with it.

Written by: Clare Verbeek, Thembani Dladla, Zanele Buthelezi
Illustrated by: Mlungisi Dlamini, Ingrid Schechter
Translated by: Erwina N. Kanyenge
Language: Rumanyo
Level: Level 1
